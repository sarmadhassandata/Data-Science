# 🔤 Natural Language Processing (NLP) & Text Mining

A structured repository containing 9 Jupyter Notebooks covering text preprocessing, tokenization, TF-IDF vectorization, SpaCy linguistic pipelines, sentiment analysis, text mining, and deep learning sequence models (RNNs) for language modeling in Python.

---

## 📂 Sequenced Learning Path

### 📖 1. Foundations & Preprocessing
- **`01_Introduction_to_Natural_Language_Processing.ipynb`** — Overview of NLP workflows, tokenization, stop-word elimination, stemming, and lemmatization.
- **`02_NLP_Basic_Concepts_and_Text_Preprocessing.ipynb`** — Regular expressions for text cleaning, corpus building, and vocabulary creation.
- **`03_NLP_Intermediate_Topics_and_Pipelines.ipynb`** — Part-of-Speech (POS) tagging, Named Entity Recognition (NER), and syntactic parsing trees.

---

### ⚙️ 2. Feature Engineering & Advanced NLP
- **`04_Feature_Engineering_for_NLP.ipynb`** — Bag-of-Words (BoW), N-grams, TF-IDF weighting, and text feature extraction strategies.
- **`05_Advanced_NLP_with_SpaCy.ipynb`** — High-performance NLP using `SpaCy`, custom pipeline components, rule-based matching, and word vectors.

---

### 💬 3. Text Mining & Sentiment Analysis
- **`06_Applied_Text_Mining.ipynb`** — Unstructured text processing, document classification, topic modeling, and term frequency distributions.
- **`07_Sentiment_Analysis_in_Python.ipynb`** — Opinion mining, lexicon-based analysis (VADER/TextBlob), and supervised classification for sentiment scoring.

---

### 🧠 4. Deep Learning & Language Modeling
- **`08_Recurrent_Neural_Networks_RNN_Fundamentals.ipynb`** — Sequential data processing, Recurrent Neural Network (RNN) architecture, hidden state persistence, and backpropagation through time (BPTT).
- **`09_Recurrent_Neural_Networks_for_Language_Modeling.ipynb`** — Next-token prediction, sequence generation, word embeddings, and RNN/LSTM language models.

---

## 🛠️ Stack & Libraries
* **Language:** Python 3.x
* **Core NLP Libraries:** `NLTK`, `SpaCy`, `TextBlob`, `VADER`
* **Deep Learning Frameworks:** `PyTorch`, `TensorFlow` / `Keras`
* **Vectorization & ML:** `Scikit-Learn`, `Pandas`, `NumPy`
