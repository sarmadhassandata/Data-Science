# 🧹 Data Wrangling & Exploratory Data Analysis (EDA)

A structured repository containing 46 hands-on projects, notebooks, and scripts focused on data cleaning, preprocessing, feature engineering, exploratory data analysis, A/B testing, and real-world domain analytics using Python, Pandas, and NumPy.

---

## 📂 Project Index

### 🧼 1. Data Cleaning, Preprocessing & Quality Assessment
- **`01_Data_Wrangling_and_Cleaning_Fundamentals.ipynb`** — Fundamentals of handling missing values, structural anomalies, and data type formatting.
- **`02_Data_Cleaning_and_Preprocessing_Pipelines.ipynb`** — Reusable data transformation pipelines for raw dataset sanitization.
- **`03_Data_Analytics_and_Data_Cleaning_Pandas.ipynb`** — Data filtering, string manipulation, and row/column transformations using Pandas.
- **`04_Data_Quality_Assessment_and_Insights.ipynb`** — Identifying data incompleteness, duplicate records, and logical outliers.
- **`05_Data_Preparation_and_Customer_Analytics.ipynb`** — Customer data aggregation, profiling, and attribute standardization.
- **`06_Pandas_Data_Joining_and_Merging.ipynb`** — Multi-table relational joins, inner/outer merges, and concatenated dataframes.
- **`07_Intermediate_Python_Data_Structures.ipynb`** — Working with complex data types, dictionary parsing, and nested lists.
- **`08_Text_Data_Cleaning_Poem_Titles.ipynb`** — String sanitization, regular expressions (Regex), and text normalization.

### 🔍 2. Exploratory Data Analysis (EDA) & Feature Engineering
- **`09_Exploratory_Data_Analysis_Fundamentals.ipynb`** — Univariate and multivariate exploratory analysis techniques.
- **`10_EDA_and_Data_Cleaning_Workflows.ipynb`** — Integrated workflow connecting cleaning routines directly to initial EDA insights.
- **`11_General_Exploratory_Data_Analysis.ipynb`** — Broad data profiling, distribution visual checks, and summary statistics.
- **`12_General_Data_Analytics_and_EDA.ipynb`** — Analytical approaches to pattern identification and correlation matrix generation.
- **`13_EDA_Car_Features_and_MSRP_Prediction.ipynb`** — Automotive dataset exploration focusing on feature correlations with vehicle price.
- **`14_Iris_Dataset_Exploratory_Data_Analysis.ipynb`** — Benchmark EDA on feature variance, pairplots, and class distributions.
- **`15_Demographic_Data_Analysis_and_Profiling.ipynb`** — Demographic segmentation analysis based on census and sample datasets.
- **`16_NLP_Feature_Engineering_and_Text_Processing.ipynb`** — Generating NLP features (tokenization, character counts, sentiment scores).
