# 🐍 Data Science Foundations & Core Principles

A structured repository containing 16 foundational Jupyter Notebooks covering core Python programming, data wrangling with Pandas, statistical analysis, baseline Machine Learning, Deep Learning frameworks (TensorFlow & Keras), Natural Language Processing, and Financial Analytics.

---

## 📂 Sequenced Learning Path

### 🐍 1. Python Programming & Object-Oriented Fundamentals
- **`01_Python_Basics_for_Data_Science.ipynb`** — Data types, control flow structures, functions, and core Python data syntax.
- **`02_Python_Object_Oriented_Programming_OOP.ipynb`** — Classes, objects, inheritance, encapsulation, and method definitions for modular programming.

---

### 🐼 2. Data Wrangling, Pandas & Ingestion
- **`03_Pandas_Fundamentals_Data_Structures_Part1.ipynb`** — Series, DataFrames, indexing, filtering, and initial data exploration.
- **`04_Pandas_Data_Manipulation_Part2.ipynb`** — GroupBy aggregations, merging tables, pivot operations, and handling missing data.
- **`05_Importing_Web_Data_and_APIs_in_Python.ipynb`** — Ingesting external web data, scraping static content, and parsing JSON API responses.

---

### 📊 3. Data Science & Statistical Principles
- **`06_Introduction_to_Data_Science_Workflows.ipynb`** — High-level overview of the end-to-end data science lifecycle and toolsets.
- **`07_Data_Science_Foundations_and_Methodologies.ipynb`** — Problem formulation, data collection strategies, and analytical frameworks.
- **`08_Statistical_Methods_for_Data_Science.ipynb`** — Probability distributions, hypothesis testing, confidence intervals, and $p$-values.
- **`09_Data_Analysis_and_Descriptive_Statistics.ipynb`** — Summary metrics, central tendency, variance, covariance, and correlation analysis.

---

### ⚙️ 4. Machine Learning & Feature Engineering
- **`10_Beginners_Guide_to_Machine_Learning.ipynb`** — First steps into supervised vs. unsupervised paradigms, target vectors, and baseline fits.
- **`11_Feature_Engineering_and_Data_Preprocessing.ipynb`** — Feature scaling, one-hot encoding, missing value imputation, and feature extraction.

---

### 🧠 5. Deep Learning, Frameworks & NLP
- **`12_Loss_Functions_and_Optimization_Metrics.ipynb`** — Mathematical formulations of MSE, Cross-Entropy, and optimization loss functions.
- **`13_Introduction_to_TensorFlow_Framework.ipynb`** — Tensors, computation graphs, and model building using the TensorFlow API.
- **`14_Deep_Learning_Fundamentals_with_Keras.ipynb`** — Multi-layer perceptrons (MLP), activation functions, sequential models, and epoch training.
- **`15_Introduction_to_Natural_Language_Processing_NLP.ipynb`** — Tokenization, stop-word filtering, text vectorization, and language processing basics.

---

### 💰 6. Financial Analytics
- **`16_Financial_Analytics_and_Python_Fundamentals.ipynb`** — Financial time-series, return calculations, portfolio risk metrics, and valuation basics.

---

## 🛠️ Stack & Technologies
* **Language:** Python 3.x
* **Core Libraries:** `Pandas`, `NumPy`, `SciPy`
* **Machine Learning & Deep Learning:** `Scikit-Learn`, `TensorFlow`, `Keras`
* **Text & Web Ingestion:** `NLTK`, `Requests`, `BeautifulSoup4`
