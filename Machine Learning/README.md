# 🤖 Machine Learning Portfolio

A comprehensive, sequentially structured collection of 52 Jupyter Notebooks covering statistical fundamentals, supervised and unsupervised learning algorithms, hyperparameter tuning, model diagnostics, NLP, recommendation engines, and end-to-end industry projects.

---

## 📂 Sequenced Learning Index

### ⚙️ 1. Foundations & Validation Strategy
- **`01_Statistical_Hypothesis_Testing.ipynb`** — Hypothesis formulation, $p$-value analysis, $t$-tests, and distribution diagnostics.
- **`02_Supervised_vs_Unsupervised_Overview.ipynb`** — Conceptual landscape comparing target-driven vs. pattern-discovery algorithms.
- **`03_Supervised_Learning_Predictive_Modeling.ipynb`** — End-to-end target prediction baseline workflows.
- **`04_Unsupervised_Learning_Pattern_Recognition.ipynb`** — Exploratory structure identification without ground-truth labels.
- **`05_Model_Validation_and_CrossValidation.ipynb`** — K-Fold, Stratified K-Fold, and cross-validation strategies.
- **`06_Supervised_Learning_Hyperparameter_Tuning.ipynb`** — GridSearch vs. RandomSearch optimization methods.

---

### 📈 2. Regression & Predictive Modeling
- **`07_Regression_Analysis_Fundamentals.ipynb`** — Ordinary Least Squares (OLS) and simple linear regression models.
- **`08_Linear_and_NonLinear_Regression.ipynb`** — Curve fitting, parametric modeling, and non-linear trends.
- **`09_Polynomial_and_Multiple_Regression.ipynb`** — Higher-degree feature expansion and multivariable regression pipelines.
- **`10_Logistic_Regression_Fundamentals.ipynb`** — Sigmoidal functions, binary decision boundaries, and log-loss functions.
- **`11_Logistic_Regression_Regularization.ipynb`** — L1 (Lasso) and L2 (Ridge) penalty impacts on classification parameters.
- **`12_Ridge_Regression_Overfitting_and_GridSearch.ipynb`** — Regularized regression tuning to limit model variance.
- **`13_Boston_Housing_Price_Regression.ipynb`** — Real estate valuation and residual error evaluation.

---

### 🎯 3. Linear Classifiers & Support Vector Machines
- **`14_Linear_Classifiers_Logistic_and_SVM.ipynb`** — Comparative analysis between Logistic Regression and Support Vector Classifiers.
- **`15_Linear_Classifiers_Prediction_Equations.ipynb`** — Geometric hyperplane formulation and prediction boundaries.
- **`16_SVM_Classification_Fundamentals.ipynb`** — Maximum margin hyperplanes, support vectors, and soft-margin parameters.
- **`17_Support_Vector_Machines_Linear_Classification.ipynb`** — Linear SVM implementations for high-dimensional feature spaces.
- **`18_Breast_Cancer_Classification_Pipeline.ipynb`** — Diagnostic clinical classification pipeline using Scikit-Learn.
- **`19_Flags_MultiClass_Classification.ipynb`** — Multi-class categorical classification architectures.

### 🌳 4. Decision Trees & Ensemble Methods
- **`20_Decision_Trees_Fundamentals.ipynb`** — Tree splitting mechanics, Gini Impurity, and Information Gain.
- **`21_Decision_Trees_Classification_and_Regression.ipynb`** — CART implementations for classification and continuous target prediction.
- **`22_Tree_Models_Bias_Variance_Diagnosis.ipynb`** — Learning curves, tree depth controls, and underfitting/overfitting trade-offs.
- **`23_Bagging_and_Random_Forest_Ensembles.ipynb`** — Bootstrap aggregation, feature random subsampling, and feature importance analysis.
- **`24_Ensemble_Boosting_AdaBoost_and_GBM.ipynb`** — Adaptive Boosting and Gradient Boosting Machine (GBM) implementations.
- **`25_CatBoost_Categorical_Classification.ipynb`** — Gradient boosting optimization tailored for categorical features.
- **`26_XGBoost_Classification_and_Regression.ipynb`** — Extreme Gradient Boosting models on tabular datasets.
- **`27_XGBoost_Hyperparameter_Tuning.ipynb`** — Optuna and GridSearch optimization for XGBoost parameters.
- **`28_XGBoost_Machine_Learning_Pipelines.ipynb`** — End-to-end integration of XGBoost into Scikit-Learn processing pipelines.
