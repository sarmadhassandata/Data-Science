# ⚙️ Data Preprocessing, Feature Engineering & Cluster Analysis

A comprehensive collection of 15 Jupyter Notebooks focused on preparing raw datasets for machine learning models. Topics include automated data ingestion, scaling transformations, feature selection strategies, dimensionality reduction techniques, and cluster analysis algorithms using Scikit-Learn, SciPy, and Pandas.

---

## 📂 Sequenced Project Index

### 📥 1. Data Ingestion & Core Transformations
- **`01_APIs_and_Data_Collection_Pipelines.ipynb`** — Fetching data via REST APIs, parsing JSON payloads, and automated ingestion workflows.
- **`02_Data_Handling_Centering_and_Scaling.ipynb`** — Mean centering, Z-score standardization, Min-Max normalization, and Robust scaling.
- **`03_Data_Preprocessing_for_Supervised_Learning.ipynb`** — Preprocessing workflows tailored for supervised classification and regression tasks in Scikit-Learn.

---

### 🛠️ 2. Preprocessing & Feature Engineering Pipelines
- **`04_Data_Preprocessing_and_Standardization.ipynb`** — Imputing missing values, handling categorical encodings, and scaling distributions.
- **`05_Feature_Selection_and_Engineering_Fundamentals.ipynb`** — Domain-specific feature creation, interaction terms, and variance thresholds.
- **`06_End_to_End_Machine_Learning_Preprocessing_Pipeline.ipynb`** — Combining transformers, encoders, and scalers using Scikit-Learn `Pipeline` and `ColumnTransformer`.
- **`07_Advanced_Feature_Engineering_Techniques.ipynb`** — Polynomial features, binning continuous variables, and target encoding strategies.

---

### 📉 3. High-Dimensional Data & Dimensionality Reduction
- **`08_Exploring_High_Dimensional_Data.ipynb`** — Diagnosing the curse of dimensionality, sparsity, and collinearity in high-dimensional spaces.
- **`09_Dimensionality_Reduction_Feature_Selection.ipynb`** — Filter methods, correlation matrices, and mutual information scoring.
- **`10_Feature_Selection_for_Model_Accuracy.ipynb`** — Wrapper methods, Recursive Feature Elimination (RFE), and L1-based regularization selection.
- **`11_Dimensionality_Reduction_Feature_Extraction.ipynb`** — Principal Component Analysis (PCA), t-SNE projection, and linear discriminant feature extraction.

---

### 🧩 4. Unsupervised Cluster Analysis
- **`12_Introduction_to_Cluster_Analysis.ipynb`** — Distance metrics (Euclidean, Manhattan, Cosine), cluster evaluation scores, and data preparation for clustering.
- **`13_KMeans_Clustering_Algorithms.ipynb`** — K-Means initialization, Elbow curve analysis, and Silhouette coefficient evaluation.
- **`14_Hierarchical_Clustering_Analysis.ipynb`** — Agglomerative hierarchical clustering, linkage criteria (ward, complete, average), and dendrogram plotting.
- **`15_Real_World_Cluster_Analysis_Applications.ipynb`** — Real-world case studies in customer profiling, market segmentation, and anomaly detection.

---

* **Language:** Python 3.x
* **Core Libraries:** `Pandas`, `NumPy`
* **Machine Learning & Preprocessing:** `Scikit-Learn`, `SciPy`
* **Visualization:** `Matplotlib`, `Seaborn`
