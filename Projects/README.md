# 🚀 End-to-End Data Science & Machine Learning Projects

A showcase repository containing 38 real-world data science, predictive modeling, operational analytics, and domain-specific machine learning projects using Python, Scikit-Learn, Pandas, PostgreSQL, and time-series forecasting.

---

## 📂 Project Index

### 💵 1. Financial, Real Estate & Market Analytics
- **`01_Bitcoin_Price_Prediction_and_Volatility_Analysis.ipynb`** — Cryptographic asset price trends and volatility forecasting models.
- **`02_Exxon_Stock_Price_Prediction_Time_Series.ipynb`** — Equity price trend estimation using financial time-series algorithms.
- **`03_Stock_Market_Price_Prediction_Algorithms.ipynb`** — Multi-stock price modeling, technical indicator extraction, and evaluation metrics.
- **`04_Oil_Tanker_Charter_Rate_Price_Prediction.ipynb`** — Commodity transport pricing and maritime charter rate predictive modeling.
- **`05_UK_House_Prices_Valuation_Analysis.ipynb`** — Residential real estate valuation, spatial price trends, and regression features in the UK market.
- **`06_Used_Cars_Price_Prediction_Model.ipynb`** — Multi-feature regression modeling for automobile depreciation and valuation prediction.
