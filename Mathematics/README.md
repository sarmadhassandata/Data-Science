# 🧮 Mathematics for Data Science & Machine Learning

This directory contains 9 structured Jupyter Notebooks covering foundational mathematics, linear algebra, multivariable calculus, and probability theory implemented using Python.

---

## 📂 Sequenced Learning Path

### 📐 1. Foundations & Calculus
- **`01_Foundational_Math_Sets_Notation_and_Inequalities.ipynb`**  
  Set theory operations, inequalities, simplification, and summation ($\sum$) notation.
- **`02_Calculus_Basics_Tangent_Lines_and_Logarithms.ipynb`**  
  Derivatives, rates of change, tangent lines, exponential growth, and logarithmic functions.
- **`03_Multivariate_Calculus_Chain_Rule.ipynb`**  
  Partial derivatives, gradient calculations, and multi-variable chain rule applications.
- **`04_Multivariate_Calculus_Jacobians_and_Hessians.ipynb`**  
  First-order (Jacobian) and second-order (Hessian) partial derivative matrices for optimization.

---

### 📏 2. Linear Algebra & Vector Spaces
- **`05_Linear_Algebra_Dot_and_Inner_Products.ipynb`**  
  Vector spaces, dot products, inner product definitions, and geometric vector properties.
- **`06_Linear_Algebra_Orthogonality_and_Angles.ipynb`**  
  Orthogonal vectors, normed spaces, vector angles, and distance metrics.
- **`07_Linear_Algebra_1D_Vector_Projections.ipynb`**  
  Vector projection formulations and geometric subspace mappings in Python.

---

### 📊 3. Statistics & Probability Theory
- **`08_Statistics_Variance_Covariance_and_Transformations.ipynb`**  
  Mean, variance, covariance matrices, and linear transformations on datasets.
- **`09_Probability_Combinatorics_and_Bayes_Theorem.ipynb`**  
  Combinatorics (permutations & combinations), conditional probability, and Bayes' Rule.

---
