# 🧮 Mathematics for Data Science & Machine Learning

This directory contains Jupyter Notebooks covering foundational mathematical concepts, linear algebra, multivariable calculus, and statistical operations implemented using Python.

---

## 📂 Included Notebooks & Topics

### 📐 Linear Algebra & Vector Spaces
- **`Dot Product & Inner Product using Python.ipynb`**  
  Vector multiplication, dot product computations, and geometric interpretations.
- **`Inner Product, Angles and Orthogonality.ipynb`**  
  Vector angles, orthogonal vectors, projection principles, and normed spaces.
- **`projection onto 1D subspaces.ipynb`**  
  Mathematical formulations and Python implementations of 1D vector projections.

---

### 📉 Calculus & Optimization
- **`Tangent Lines to Functions, Exponents and Logarithms.ipynb`**  
  Derivatives, rates of change, exponential growth, and logarithmic functions.
- **`Multivariate Chain Rule.ipynb`**  
  Partial derivatives, gradient calculations, and chain rule application in multidimensional functions.
- **`Jacobians and Hessians.ipynb`**  
  First-order (Jacobian) and second-order (Hessian) partial derivative matrices for optimization algorithms.

---

### 📊 Probability & Statistics
- **`Sets, Number Line, Inequalities, Simplification, and Sigma Notation.ipynb`**  
  Fundamental mathematical notation, set theory operations, and summation notations ($\sum$).
- **`Bayes Theorem, Combinations & Permutations.ipynb`**  
  Combinatorics calculations, conditional probability, and Bayes' Rule implementations.
- **`Mean, Variance, Covariance & Linear Transformation using python.ipynb`**  
  Descriptive statistical measures, covariance matrices, and linear transformations on time-series/tabular datasets.

---

## 🛠️ Python Libraries Used
- `NumPy`
- `SymPy` / `SciPy`
- `Matplotlib`
