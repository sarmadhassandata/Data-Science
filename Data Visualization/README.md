# 📊 Data Visualization with Python

A structured collection of 8 Jupyter Notebooks covering statistical plotting, custom aesthetic themes, regression graphics, text visual analytics, and geospatial mapping using Python's core visualization stack (`Matplotlib`, `Seaborn`, `Folium`, and `WordCloud`).

---

## 📂 Sequenced Project Index

### 📉 1. Foundations & Core Visual Engine
- **`01_Matplotlib_Fundamentals_and_Line_Plots.ipynb`** — Figure/Axes hierarchy, line properties, markers, axis labeling, and multi-series line plots.
- **`02_Data_Visualization_Fundamentals_Matplotlib.ipynb`** — Layout customization, subplots, grid formatting, and figure exporting formats.
- **`03_Introduction_to_Seaborn_Data_Visualization.ipynb`** — High-level statistical plot API, dataframe integration, and built-in color palettes.
- **`04_Intermediate_Seaborn_Customization_and_Themes.ipynb`** — FacetGrid, PairGrid, theme styling, and advanced aesthetic configurations.

---

### 📊 2. Distributional & Statistical Visualizations
- **`05_Distribution_Plots_Area_Histograms_Bar_Charts.ipynb`** — Cumulative area charts, frequency distributions, kernel density estimations (KDE), and stacked bar charts.
- **`06_Statistical_Plots_Scatter_Box_Bubble_Pie_Charts.ipynb`** — Bivariate relationships, 3D bubble sizing, outlier detection via box plots, and proportional pie charts.

---

### 🗺️ 3. Advanced, Text & Geospatial Analytics
- **`07_Advanced_Visualizations_Waffle_Regression_WordClouds.ipynb`** — Proportional waffle charts, linear regression scatter fits, and text frequency word clouds.
- **`08_Geospatial_Data_Visualization_and_Mapping_Folium.ipynb`** — Interactive geospatial mapping, choropleth maps, geo-JSON boundary rendering, and marker clusters using Folium.

---

## 🛠️ Tech Stack & Libraries
* **Core Plotting:** `Matplotlib`, `Seaborn`
* **Geospatial & Interactive:** `Folium`, `GeoPandas`
* **Text Analytics & Special Visuals:** `WordCloud`, `PyWaffle`
* **Data Wrangling Integration:** `Pandas`, `NumPy`
